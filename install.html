安装步骤

  1. 点上面的按钮下载，浏览器提示保留文件时确认保留。
  2. 打开下载完成的文件；系统若询问，允许本次「安装未知来源应用」。
  3. 装完打开应用即可看到警报、停电与供水信息：本版本已预置下方数据服务地址。
  4. 若换了 Wi-Fi 或电脑 IP 有变，才需在「设置 → 数据服务地址」改填新地址。覆盖安装不会丢失已保存的设置。
